# Acceso y privacidad de ScoutApoya CHN

## Acceso a la comunidad
Los proyectos y folios son visibles únicamente para miembros aprobados. La solicitud de acceso es revisada manualmente por el único administrador, que puede aprobarla o rechazarla. El sitio no sustituye controles de seguridad perimetrales ni auditorías de permisos.

## Código en GitHub
El repositorio actual `b3njaram/raffles` es público según la consulta más reciente. Para hacerlo privado, entra a https://github.com/b3njaram/raffles/settings → General → Danger Zone → Change repository visibility → Private. Verifica después que Vercel sigue conectado al repositorio.

Los paquetes de JavaScript enviados al navegador no se convierten en secretos cuando GitHub se marca como privado. No incorpores credenciales secretas en el cliente.

## Causas
Esta versión opera exclusivamente con causas solidarias, intenciones de apoyo y acuses únicos. No hay cobros ni documentación fiscal generada. Se retiraron los puntos de acceso de actividades anteriores y las tablas históricas permanecen como archivo, sin permisos ordinarios de lectura/escritura.

## Donaciones reales
Para recibirlas se debe tener una entidad receptora definida, método de cobro y verificación de pagos. Las intenciones que guarda la aplicación no deben confundirse con dinero recaudado ni CFDIs.
